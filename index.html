استرجاع جميع الحسابات — ملفات الموقع تشغيل محلياً ثبّت Node.js 18 أو أحدث. افتح مجلد المشروع ونفّذ: npm install عيّن متغيري البيئة BOT_TOKEN وCHAT_ID على الخادم. شغّل: npm start افتح http://localhost:3000 إعداد تليجرام BOT_TOKEN: رمز البوت، يوضع في إعدادات Environment Variables لدى شركة الاستضافة فقط. CHAT_ID: استخدم الرقم الذي زودتني به في إعدادات الخادم. لا تضع BOT_TOKEN في ملفات الواجهة أو ترسله في محادثة عامة. النشر ارفع مجلد المشروع إلى استضافة تدعم Node.js 18+، واضبط أمر التشغيل npm start، وأضف متغيرات البيئة أعلاه. استخدم HTTPS. الخصوصية والسلامة لا تطلب كلمات مرور أو رموز تحقق أو بيانات بطاقات مصرفية. النموذج مخصص للحسابات التي يملكها مقدم الطلب أو لديه تفويض بإدارتها. الخدمة مستقلة وغير تابعة للمنصات، ولا تضمن نجاح الاسترجاع. الملفات المرفوعة تحفظ مؤقتاً على الخادم ثم يحاول التطبيق حذفها بعد إرسالها. قبل الإطلاق، أضف سياسة خصوصية واضحة وبيانات تواصل حقيقية، واختبر الإرسال بحسابك.
